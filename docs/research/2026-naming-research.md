> ## ⛔ DOMAIN VERIFICATION — read before trusting any availability claim in this doc
> **`.co` and `.io` publish NO RDAP service** (IANA bootstrap returns empty endpoints). The **rdap.org** redirector answers those with HTTP 404, which is **"this TLD has no RDAP," NOT "domain available."** Reading that 404 as "free" produced a whole session of **false-free `.co`/`.io` claims** (e.g. Zeenah, Sundus, Izzah were all reported `.co`/`.io`-free but are taken). **Reliable per-TLD method (USE THIS):** `.com` → `rdap.verisign.com/com/v1` · `.app` → `pubapi.registry.google/rdap` · `.ca` → `rdap.ca.fury.ca/rdap` (all real RDAP, 404 = free) · **`.io` → WHOIS port 43 `whois.nic.io`** · **`.co` → DNS-NS heuristic or a registrar** (NS present = taken; NS absent = *likely* free, confirm at registrar — do NOT treat as certain). Earlier lesson still stands: never use `NS`-only or rdap.org for ccTLDs.

## 1. Naming criteria checklist (the bar)

- **Spell-on-first-hearing** (phone test) — no silent letters / ambiguous vowels
- **Memorable** after an hour
- **Short** — 4–8 letters, 1–3 syllables; one word beats two
- **Pronounceable**, good rhythm, clean in English + the audience's languages
- **Brandable > descriptive** — distinctive/ownable beats literal
- **Semantic hook** — hints at meaning/feel without being a literal label
- **App-store legal** — ≤30 chars; no "free/best/#1"
- **Trademark clearance** — CIPO + USPTO, Nice **class 25 (apparel)** + **35 (retail)**
- **Domain reachable** — `.com`/`.ca` ideal; clean compound (`the-`, `wear-`, `.app`) acceptable
- **SEO/discoverability**
- **Cultural fit** — universal across Muslim backgrounds, not preachy; no negative cross-language meaning

## 4. Meta-finding (the pattern)

**Literal/descriptive Arabic words for "modesty/covering" (Haya, Hishma, Fitra, Kiswa, Iffa, Libas…) are universally crowded** in modest fashion — multiple existing brands per word — AND often domain-taken. Three independent deep-vets (Fitra, Hishmah, Kiswa) all returned **RECONSIDER for the same structural reason**.
**Direction: go DISTINCTIVE / oblique / coined, not literal.** Names that name a *feeling* (elegance, a star) rather than the category itself dodge the trap.

## 6. Verification method (for reproducibility)

- **Domain availability — PER-TLD AUTHORITATIVE METHOD (two methods already failed; see the ⛔ callout up top).** ❌ `NS`-only lookups miss registered-but-parked domains (false "free"). ❌ **rdap.org for `.co`/`.io` returns 404 because those ccTLDs have NO RDAP — NOT because the domain is free** (this produced the false-free Zeenah/Sundus/Izzah `.co`/`.io` data). ✅ **Correct, per-TLD:** `.com` → `https://rdap.verisign.com/com/v1/domain/<n>` · `.app` → `https://pubapi.registry.google/rdap/domain/<n>` · `.ca` → `https://rdap.ca.fury.ca/rdap/domain/<n>` (all true RDAP: 404 = free, JSON = taken w/ `events[registration]`) · **`.io` → WHOIS port 43 to `whois.nic.io`** (no RDAP) · **`.co` → DNS-NS heuristic or registrar** (no RDAP, WHOIS port often refused; NS present = taken, NS absent = *likely* free → **confirm at registrar**). Discover any TLD's real RDAP base from the IANA bootstrap `https://data.iana.org/rdap/dns.json`. Registrar is always the final source of truth before purchase.
- **Class-aware trademark (current rule):** the app is Nice class **9** (app software), **42** (SaaS), **35** (online retail/affiliate). Clothing is class **25 = adjacent**. HIGH/OUT = live registered mark in 9/35/42 **or** an exact-name established fashion brand; MEDIUM/coexist-OK = small/unregistered class-25 shop only; LOW = clean. Small Etsy-tier namesakes do **not** disqualify.
- **Deep-vet:** fan-out web research per dimension — trademark, app-store collisions, social handles, cultural/religious fit, cross-language meaning. Unconfirmable items labelled **"unverified — check manually."**
- **Before buying any name:** RDAP-confirm domains + manually check `.ca` + run CIPO + USPTO searches in classes **9 / 35 / 42** + an app-store search.

### 7a. Audience-language findings (2026) — useful beyond naming

- **Two non-overlapping registers.** Millennial/quiet-luxury = *feeling* words ("covered," "coverage," "effortless," "quiet luxury," "covered but couture"). Gen-Z/streetwear = *TikTok* ("fit," "fit check," "drip," "modest baddie," "halalify," "halal fit," "modest but make it fashion"). Don't blend the lecture register into either.
- **Modesty is framed as a styling constraint, not a virtue** — "coverage," "loose," "layering," "longline," "high-neck," "full-length," "no sheer," "lined." This *is* the product's filter vocabulary; label filters in it.
- **Moralizing is resented** ("modesty is beauty," "reclaim your modesty" read as a capitalist façade). Never sermonize on faith.
- **Trend is toward effortless/seamless**, away from elaborate pin tutorials and heavy fabric jargon.
- **Don't ethnically default** (abaya/kaftan ≠ "modest fashion"); the market isn't monolithic.
- **"Modest" is a safe neutral category label;** the exhausted naming roots to avoid: Noor/Nour/Haya, literal "Modest-" prefix, "Grace," Veil/Vela/Vera. Nearest AI-discovery rivals **Slate** and **Plush** prove the fresh register: short, neutral, secular English nouns that let the product carry the modesty signal.
